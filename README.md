# 🤖 Machine Learning Repository

This is my personal **Machine Learning learning repo** 📚  
I built it with the **intent of understanding ML step by step** and applying those concepts in practice.  
Every notebook here is a **building block** toward becoming strong in ML.  

👉 I have applied these concepts in my real-world project:  
[🏡 Bangalore Home Price Prediction](https://github.com/ankiibott/Home_price_prediction)  

---

## 📂 Topics Covered

### 🔑 Core Algorithms
- **Linear Regression/** → I understood how regression predicts continuous values.  
- **Logistic Regression/** → I studied binary classification using logistic functions.  
- **Naive_bayes/** → I explored probability-based classification with Bayes’ theorem.  
- **DecisionTree.ipynb** → I learned how decision trees split data into rules.  
- **RandomForestAlgo.ipynb** → I extended my learning to ensembles of decision trees.  
- **SVM.ipynb** → I studied Support Vector Machines to classify data with hyperplanes.  
- **KMeansCluster.ipynb** → I practiced unsupervised learning with clustering.  

---

### 📊 Training & Model Validation
- **TrainingTest.ipynb** → I understood the importance of splitting train/test data.  
- **kfold CrossValidation.ipynb** → I applied K-Fold cross-validation for robust evaluation.  
- **HyperParameter.ipynb** → I practiced tuning hyperparameters for better models.  

---

### ⚙️ Optimization & Regularization
- **GradientDescent.ipynb** → I implemented gradient descent to minimize errors.  
- **L1&L2Regulariscation.ipynb** → I studied L1 (Lasso) and L2 (Ridge) regularization to avoid overfitting.  

---

### 📉 Dimensionality Reduction
- **Dimensionality_reduction/** → I explored PCA and other techniques to reduce feature space.  

---

### 🛠️ Encoding & Model Saving
- **One_Hot_Encoding/** → I learned how to encode categorical variables for ML models.  
- **model_joblib/** → I saved trained ML models using `joblib`.  
- **model_pickle/** → I also used `pickle` for model persistence.  
- **Extract_model/** → I extracted and reused models for deployment.  

---

## 🛤️ My Learning Path

I built this repo with a **structured intent to understand ML concepts** in the following order:

1. 📈 Start with **Linear Regression** → regression basics  
2. ✅ Move to **Logistic Regression** → binary classification  
3. 🌳 Explore **Decision Trees & Random Forests**  
4. ➗ Learn **Naive Bayes & SVM** for classification  
5. 🎯 Practice **KMeans Clustering** for unsupervised learning  
6. ⚙️ Study **Gradient Descent & Regularization**  
7. 🧪 Apply **Cross Validation & Hyperparameter tuning**  
8. 🗂️ Learn **Dimensionality Reduction**  
9. 💾 Save & deploy models with **Pickle/Joblib**  
10. 🚀 Apply everything in [🏡 Home Price Prediction](https://github.com/ankiibott/Home_price_prediction)  

👉 This structured flow **helped me a lot to understand Machine Learning** step by step.
